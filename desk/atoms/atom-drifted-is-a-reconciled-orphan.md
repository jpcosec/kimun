# Drifted is a reconciled orphan

## Answer

Drifted is not a fourth parallel anchor state but a refinement of orphan. The kernel computes intact, superseded and orphan with no heuristic at all. Reconciliation then takes each orphan and looks for a candidate replacement — by position, when the old node held a path in the base revision that a different node of the same class and kind now holds; by fingerprint, when two external nodes share a locator and differ in their digest; or by Dice similarity over the multiset of grapheme trigrams of the comparable text. When a candidate is named the orphan is reported as drifted with that confidence. A proposal lives outside the pool, being neither node nor edge, until an actor accepts it; accepting is an ordinary transaction that adds a supersedes edge whose only evidence is that actor, after which the re-anchoring rules apply and the anchor becomes superseded. The confidence and the method never enter the edge, because whoever answers for the succession is the actor who accepted it and not the heuristic that proposed it.
