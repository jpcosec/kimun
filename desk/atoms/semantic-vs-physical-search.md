# Semantic vs physical search

## Answer

Physical search matches names, paths, and structure, while semantic search matches meaning-like tags and section meaning.

## Supporting points

- Users choose physical search when they know a path-like token.
- Users choose semantic search when they know a concept-like meaning.
- This split is a durable retrieval contract.
